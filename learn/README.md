# GrokLang 语言教程

本目录是 **GrokLang**（配合工具包 **GrokLangToolKit / gltk**）的系统化入门教程。  
目标：读完并动手练习后，你能独立写出、运行并打包自己的 `.glk` 程序，并在逆向分析场景中使用语言自带的原生能力。

## 你将学到什么

- 这门语言**为什么存在**，它解决逆向工程里的哪类问题  
- 源码 → 字节码 → 虚拟机 / 打包 exe 的完整链路  
- 语法、标准库、Native 模块（PE、加密、网络、GUI 等）  
- 如何写可复现的分析脚本，以及如何交付独立工具

## 环境准备（所有章节通用）

在 Windows 上，进入工具包根目录：

```powershell
cd D:\grokbuild\groklang\gltk
go build -o gltk.exe ./cmd/gltk
.\gltk.exe version
```

确认能打印版本（当前文档编写时为 **0.5.x**）后，再按各章示例运行。

## 约定

- 源码扩展名：`.glk`
- 字节码扩展名：`.glkb`
- 入口函数：`fn main(args) { ... }`（`args` 为命令行参数字符串数组）
- 行注释：`// ...`
- 示例默认在 **仓库根目录** 执行命令，路径写成 `learn/...` 或 `samples/...`
