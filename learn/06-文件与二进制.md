## 6.0 模块分工

| 模块 | 职责 |
|------|------|
| `fs` | 路径是否存在、读文本/字节、写文件、列目录、walk、按范围读 |
| `bin` | 在 **bytes** 上取 u8/u16le/u32le、slice、查找、填充、校验和 |

```text
磁盘文件 --fs.read_bytes--> bytes --bin.u16le--> 整数字段
     ^                                              |
     +------------- fs.write_bytes <--- bin.* 修改 --+
```

## 6.7 与第 4 章伪字节数组的关系

| 第 4 章 `array` of int | 第 6 章 `bytes` + `bin` |
|------------------------|-------------------------|
| 教学模拟 | 真实 API |

## 6.8 推荐脚本骨架

```glk
import out, fs, bin

fn analyze(path) {
  if !fs.exists(path) {
    return {ok: false, error: "missing"}
  }
  let n = fs.file_size(path)
  let hdr = fs.read_range(path, 0, 64 < n ? 64 : n)
  let magic = bin.u16le(hdr, 0)
  return {ok: true, path: path, size: n, mz: magic == 0x5A4D}
}

fn main(args) {
  let path = len(args) > 0 ? args[0] : "gltk.exe"
  let r = analyze(path)
  if !r.ok {
    out.println(r.error)
    return 1
  }
  out.println(r.path, "size", r.size, "mz", r.mz)
  return 0
}
```

## 6.9 常见错误

| 问题 | 处理 |
|------|------|
| `cannot convert array to bytes` | 用 `bin.from_u32le`/`concat` 造 bytes，别把普通 array 当 bytes |
| 路径不存在 | `fs.exists`；注意工作目录 |
| 大文件 OOM | `read_range`/`head`，别 `read_bytes` 整个 |
| 端序搞反 | PE 等用 **LE**：`u16le/u32le` |
| list_dir 元素是字符串名 | 拼路径时加目录前缀 |
| 嵌套 fn 给 async | 顶层函数（第 5 章） |

## 6.12 小结

1. **`fs`** 负责磁盘与路径；**`bin`** 负责 bytes 视图。  
2. 造 bytes 用 `from_u32le` / `concat` / `write_at` / `fill`。  
3. 大文件用 **range/head**。  
4. 魔数检测是最小可用 RE 脚本。  
5. 与 async 组合即批处理扫描器。
