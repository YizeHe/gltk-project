## 4.0 为什么单独开一章？

逆向与工具脚本里，90% 的数据长这样：

| 形态 | 语言对应 | 例子 |
|------|----------|------|
| 字节序列 / 表 | `array` | section 列表、扫描缓冲 |
| 记录 / 字典 / 配置 | `map` | PE 头字段、选项、频率统计 |
| 文本 | `string` + `str` 模块 | 路径、日志、协议 ASCII |

三者经常**嵌套**：

```text
map
 ├─ file: string
 ├─ tags: array of string
 └─ sections: array of map { name, size }
```

本章按「先容器、再字符串工具、再组合模式」展开。

## 4.1 数组（array）

### 4.1.1 字面量与类型

```glk
let empty = []
let xs = [10, 20, 30]
out.println(typeof(xs))  // array
out.println(len(xs))     // 3
```

- 下标从 **0** 开始；  
- 元素类型可变（动态类型），但建议同质；  
- `len(arr)` 为元素个数。

### 4.1.2 读写下标

```glk
xs[0]
xs[len(xs) - 1]
xs[1] = 99
```

越界 → 运行时错误。扫描前先保证 `i < len(arr)`。

### 4.1.3 引用语义

```glk
let ys = xs
ys[0] = 1
// xs[0] 也是 1
```

`ys` 与 `xs` 指向**同一数组对象**。需要独立副本时，要自行循环拷贝到新数组（无内建 `clone` 时手写）。

### 4.1.4 遍历

```glk
// 元素
for v in xs { ... }

// 下标
for i in range(0, len(xs)) {
  out.println(i, xs[i])
}
```

### 4.1.5 固定长度「缓冲区」

没有动态 `push` 时，常用：

```glk
let tab = [0, 0, 0, 0, 0]
for i in range(0, 5) {
  tab[i] = i * i
}
```

或只遍历不收集（统计、查找、打印）。

### 4.1.6 嵌套数组

```glk
let mat = [[1, 2], [3, 4]]
out.println(mat[1][0])  // 3
```

### 4.1.7 可运行

```powershell
.\gltk.exe run learn\examples\ch04_01_arrays.glk
.\gltk.exe run learn\examples\ch04_02_array_algos.glk
```

`ch04_02` 含：`index_of`、`count_gt`、原地反转、选择排序、`min_max`、打印辅助。

## 4.2 映射（map）

### 4.2.1 字面量

```glk
let pe = {
  machine: 0x8664,
  "entry": 0x1000,
  name: "sample.exe"
}
```

键可以是：

- 标识符 `name` → 字段名 `"name"`；  
- 字符串 `"entry"` → 任意键名。

### 4.2.2 访问

```glk
pe.name
pe["name"]
pe.sections = 5
pe["sections"] = 6
```

`len(pe)` → 键的数量。

### 4.2.3 空 map + 赋值（安全）

```glk
let host = "api.local"
let cfg = {}
cfg.host = host
cfg.port = 443
```

**切记第 2 章纪律**：顶层全局变量直接写进 `{ "k": 全局名 }` 可能变成 `null`；配置请用字面量或先 `{}` 再赋值。

### 4.2.4 遍历

```glk
for k in cfg {
  out.println(k, cfg[k])
}
```

迭代的是**键**；顺序不稳定。

### 4.2.5 存在性

读取不存在的键通常得到假值（如 `null`），可用于：

```glk
if freq["pe"] {
  // 存在且非假
}
if !freq["bin"] {
  // 不存在或为假
}
```

### 4.2.6 作计数器 / 集合

```glk
let freq = {}
for w in words {
  if freq[w] {
    freq[w] = freq[w] + 1
  } else {
    freq[w] = 1
  }
}
```

集合：`seen[key] = true`，判断 `if seen[key]`。

### 4.2.7 嵌套 map / 数组

```glk
let report = {
  meta: {tool: "gltk"},
  hits: [0x100, 0x200]
}
report.meta.tool
report.hits[0]
```

也可用逐步赋值构造深层结构（见 `ch04_07`）。

### 4.2.8 可运行

```powershell
.\gltk.exe run learn\examples\ch04_03_maps.glk
```

## 4.4 `str` 模块（必须会）

```glk
import str
```

### 4.4.1 API 一览（实践常用）

| 函数 | 作用 | 示例直觉 |
|------|------|----------|
| `str.lower` / `str.upper` | 大小写 | 扩展名比较前 lower |
| `str.trim` | 去首尾空白 | 解析配置行 |
| `str.len` | 长度 | 与内建 `len` 类似 |
| `str.contains` | 是否包含子串 | 特征串 |
| `str.starts_with` / `ends_with` | 前后缀 | `has_prefix` / `has_suffix` 别名 |
| `str.index_of` | 子串位置，没有则负 | 找分隔符 |
| `str.slice` / `substr` | 子串 `[start, end)` | 切 key/value |
| `str.split` | 分割 → **数组** | CSV、路径 |
| `str.join` | 数组 → 字符串 | 反向拼接 |
| `str.replace` | 替换 | 统一 `\` 为 `/` |
| `str.repeat` | 重复 | 调试 |
| `str.url_encode` | URL 编码 | 请求构造 |
| `str.scan` 等 | 逆向扫字符串 | 后续 PE 章节会用 |

### 4.4.2 重要：`import str` 之后

不要写 `str(42)` 做转换（名字是模块 map）。转换用：

```glk
"" + n
to_str(n)
```

### 4.4.3 组合模式：扩展名

```glk
let lower = str.lower(file)
if str.ends_with(lower, ".exe") {
  // ...
}
```

### 4.4.4 可运行

```powershell
.\gltk.exe run learn\examples\ch04_05_str_module.glk
```

## 4.5 字符串解析模式

### 4.5.1 basename

统一分隔符再 `split`，取最后一段：

```glk
let p = str.replace(path, "\\", "/")
let parts = str.split(p, "/")
return parts[len(parts) - 1]
```

### 4.5.2 `key=value`

用 `index_of` 找第一个 `=`，再 `slice` 两段，`trim` 空白。

### 4.5.3 多行配置

`split(text, "\n")` → 逐行：跳过空行与 `#` 注释 → `parse_kv` → 写入 map。

### 4.5.4 可运行

## 4.7 表：数组 of map

把「表格」建成：

```glk
let rows = [
  {name: "a.exe", arch: "x64", size: 12000, packed: false},
  {name: "b.exe", arch: "x86", size: 8000, packed: true}
]
```

然后：

- **过滤**：`if r.arch == "x64"`  
- **聚合**：累加 `r.size`  
- **投影**：只打 `r.name`  
- **字符串条件**：`str.ends_with(str.lower(r.name), ".exe")`

```powershell
.\gltk.exe run learn\examples\ch04_08_table.glk
```

这是写库存扫描、样本清单时最常用的形状。

## 4.10 选型指南

| 你想表达… | 用 |
|-----------|----|
| 有序列表、缓冲、栈式下标访问 | `array` |
| 命名字段、字典、配置、JSON 对象 | `map` |
| 路径、日志、协议文本 | `string` + `str` |
| 对外交换/落盘结构 | `json.stringify` |
| 样本清单/多行记录 | `array` of `map` |
| 二进制 | 字节数组 + 日后 `bin`/`fs` |

## 4.11 常见错误

| 症状 | 原因 | 处理 |
|------|------|------|
| 改 `b[0]` 影响 `a` | 数组引用 | 需要拷贝时循环赋值 |
| map 字面量字段 null | 全局变量进 `{}` | 字面量或先 `{}` 再赋 |
| `str(1)` 报错 | 模块覆盖函数名 | `to_str` / `""+` |
| `for x in map` 得到键 | 设计如此 | `m[x]` 取值 |
| split 后带空格 | 未 trim | `str.trim(parts[i])` |
| 路径 `\` 丢失 | 字符串转义 | `\\` 或 `/` |
| slice 越界 | end/start 非法 | 先 `len` 与 `index_of` |
| 空数组取 `[0]` | 越界 | 先判断 `len` |

## 4.15 小结

1. **数组**负责顺序与下标算法；注意引用语义与越界。  
2. **map**负责记录、配置、计数、JSON 对象；遍历得键。  
3. **字符串**负责文本；插值与多行写报告很爽。  
4. **`str` 模块**是文本处理标准库；与转换函数 `str()` 名字冲突要避开。  
5. **array of map + str 过滤** = 轻量数据表。  
6. **int 数组**可先模拟字节，再接到真正的文件/二进制 API。
