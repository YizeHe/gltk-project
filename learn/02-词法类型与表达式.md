## 2.1 源码如何变成 Token（词法总览）

当你执行：

```powershell
.\gltk.exe run learn\examples\ch02_01_comments_idents.glk
```

工具链内部大致是：

```text
源文字符串
   │
   ▼
词法分析器 Lexer  ──►  Token 流（标识符、数字、关键字、运算符……）
   │
   ▼
语法分析器 Parser ──►  AST（抽象语法树）
   │
   ▼
编译器 Compiler  ──►  字节码 Chunk
   │
   ▼
GLVM 执行
```

**词法阶段**只关心：空白如何跳过、注释如何丢掉、一串字符如何切成最小有意义单元（Token）。

GrokLang 的 Token 类别在实现上包括（概念列表，不必背代码名）：

| 大类 | 例子 |
|------|------|
| 字面量 | `42` `3.14` `"hi"` `true` `false` `null` |
| 标识符 | `count` `userName` `_tmp` |
| 关键字 | `fn` `let` `if` `return` … |
| 运算符 | `+` `==` `&&` `?` `<<` … |
| 标点 | `( ) { } [ ] , : .` |

本章大部分内容，就是这些 Token 在**语言层面的合法写法**与**组合语义**。

## 2.2 空白与注释

### 2.2.1 空白

空格、制表符、换行在词法阶段被跳过，**不产生 Token**（字符串字面量内部的空白除外）。

因此下面两段在语法上等价：

```glk
let x=1+2
```

```glk
let x = 1 + 2
```

**风格建议**：运算符两侧加空格，`,` 后加空格，提高可读性。语言本身不强制。

### 2.2.2 行注释

```glk
// 从双斜杠到本行结束都是注释
let x = 1 // 行尾注释也可以
```

### 2.2.3 块注释

```glk
/*
  多行说明
  可以写很久
*/
let y = 2
```

注意：

- 块注释以 `/*` 开始、以 `*/` 结束；  
- 当前实现是**常规非嵌套**风格：内层再写 `/*` 不会开新一层（与 C 类似，不要依赖嵌套块注释）；  
- 注释**不会**进入运行时，也不占用变量名。

### 2.2.4 可运行示例

```powershell
.\gltk.exe run learn\examples\ch02_01_comments_idents.glk
```

对应文件：`learn/examples/ch02_01_comments_idents.glk`。

## 2.3 标识符与关键字

### 2.3.1 标识符规则

标识符（变量名、函数名、字段名等）满足：

```text
首字符：字母 A–Z / a–z 或下划线 _
后续：字母、数字或下划线
```

正则直觉：`[A-Za-z_][A-Za-z0-9_]*`

| 合法 | 非法 |
|------|------|
| `x` `count` `_tmp` `n2` `userName` | `2n`（数字开头） |
| `HTTP_OK` | `user-name`（含 `-`，会被拆成减号） |
| | `let` `if` `fn`（关键字占用） |

GrokLang 标识符按 **ASCII 字母数字** 设计；**不要用中文作标识符**（字符串内容可以中文）。

### 2.3.2 关键字完整表

下列单词是**关键字**，不能作为普通标识符：

| 关键字 | 典型用途（第 2 章只需认识） |
|--------|------------------------------|
| `fn` | 定义函数 |
| `let` | 绑定变量 |
| `if` `else` | 条件（第 3 章详解） |
| `while` `for` `in` | 循环 |
| `return` | 返回 |
| `import` `as` | 导入模块 |
| `true` `false` | 布尔字面量 |
| `null` | 空值 |
| `break` `continue` | 循环控制 |
| `switch` `case` `default` | 分支 |
| `try` `catch` `throw` | 错误处理 |

### 2.3.3 大小写

语言**区分大小写**：

```glk
let Answer = 1
let answer = 2
// Answer 与 answer 是两个名字
```

关键字必须全小写：`True` 不是布尔关键字，而是普通标识符（若未定义则会报错）。

## 2.4 数字：整数、十六进制、浮点

### 2.4.1 十进制整数

```glk
let a = 0
let b = 42
let c = -7
```

负号是一元运算符，不是数字字面量的一部分（词法上通常是 `MINUS` + `INT`）。

### 2.4.2 十六进制整数

前缀 `0x` 或 `0X`：

```glk
let hx = 0xFF      // 255
let mz = 0x4D5A    // PE 文件头 'MZ' 的常见写法之一
```

逆向场景中十六进制极常用：魔数、RVA、标志位等。

### 2.4.3 浮点数

```glk
let pi = 3.14
let thousand = 1e3      // 1000.0
let small = 2.5e-1      // 0.25
```

`typeof(1)` 为 `"int"`，`typeof(1.0)` 为 `"float"`——**带小数点或指数的是浮点**。

### 2.4.4 算术运算

| 运算符 | 含义 | 备注 |
|--------|------|------|
| `+` `-` `*` | 加、减、乘 | 数字运算；`+` 见字符串节 |
| `/` | 除 | **两个 int → 整除**（向 0 截断），`7/2 == 3` |
| `%` | 取余 | 整数场景 |

```glk
out.println(7 / 2)     // 3
out.println(7.0 / 2)   // 3.5
out.println(7 / 2.0)   // 3.5
out.println(7 % 2)     // 1
```

**务必记住整除**：写过 Python 3 的人容易踩坑（Python 3 的 `/` 总是真除）。

### 2.4.5 位运算

| 运算符 | 含义 |
|--------|------|
| `&` `|` `^` | 按位与、或、异或 |
| `~` | 按位取反 |
| `<<` `>>` | 左移、右移 |

```glk
out.println(5 & 3)   // 1
out.println(5 | 3)   // 7
out.println(1 << 4)  // 16
```

位运算主要面向整数；逆向里做 flag 掩码、对齐计算时会用到。

### 2.4.6 可运行示例

```powershell
.\gltk.exe run learn\examples\ch02_02_numbers.glk
```

请对照输出核对 `7/2` 与 `7.0/2`。

## 2.5 字符串

字符串是 GrokLang 里最常用的类型之一：路径、日志、协议字段、反编译出来的文本都是字符串。

### 2.5.1 字面量形式

| 形式 | 示例 | 说明 |
|------|------|------|
| 双引号 | `"hello"` | 最常用；支持 `${插值}` |
| 单引号 | `'world'` | 与双引号类似 |
| 三引号 | `"""多行..."""` | 可跨行，可插值 |

### 2.5.2 转义序列

在引号字符串内：

| 转义 | 含义 |
|------|------|
| `\n` | 换行 |
| `\t` | 制表符 |
| `\r` | 回车 |
| `\\` | 反斜杠 |
| `\"` | 双引号 |
| `\'` | 单引号 |
| `\$` | 字面 `$`（避免被当成插值开头时可用） |
| `\xHH` | 十六进制字节（如 `\x41` → `A`） |

```glk
out.println("line1\nline2")
out.println("say \"hi\"")
```

Windows 路径在字符串里写反斜杠时要注意转义：

```glk
// 推荐正斜杠（多数 API 可接受）
let p1 = "D:/data/sample.bin"
// 或双反斜杠
let p2 = "D:\\data\\sample.bin"
```

### 2.5.3 拼接与 `+` 的重载语义

运算符 `+`：

- 两侧都是数字 → 算术加；  
- **任一端是字符串** → **字符串拼接**（另一端会转成文本形式）。

```glk
out.println(1 + 2)          // 3
out.println("n=" + 42)      // n=42
out.println("" + true)      // 类似 true 的文本
```

**推荐习惯**：需要「数字变字符串」时写：

```glk
let s = "" + n
// 或
let s2 = to_str(n)
```

### 2.5.4 为什么尽量不用 `str(n)`？

语言文档里有全局函数 `str(x)`，但运行时还会注册 **Native 模块** 名叫 `str`。  
`gltk run` 启动时会把模块写进全局表，**模块名 `str` 会盖住函数 `str`**，导致：

```glk
str(42)   // 运行时错误：cannot call map
```

因此：

| 做法 | 是否推荐 |
|------|----------|
| `"" + x` | ✅ 最稳 |
| `to_str(x)` | ✅ 稳妥（别名） |
| `str(x)` | ⚠️ 易踩坑 |
| `import str` 后再 `str.slice` | 模块用法，与函数无关 |

`import str` 时你是在用**字符串工具模块**（`str.slice`、`str.contains` 等），这是另一回事。

### 2.5.5 字符串插值 `${...}`

在**双引号**或**三引号**字符串中，`${表达式}` 会在编译期展开为拼接：

```glk
let name = "Grok"
let ver = 5
out.println("hello ${name}, v${ver}")
// 约等于 "hello " + name + ", v" + ver

out.println("sum=${1 + 2}")  // sum=3
```

插值里可以是变量、算术、甚至函数调用（保持简短以免难读）。

**注意**：插值是编译期语法糖，不是运行时模板引擎；表达式必须是合法 GrokLang 表达式。

### 2.5.6 多行字符串

```glk
let doc = """第一行
第二行
第三行"""
```

适合：多行帮助文本、嵌入一小段固定配置、生成报告。

### 2.5.7 长度

```glk
len("hello")  // 5
```

`len` 是内建全局函数，对字符串、数组、映射等有定义（映射一般是键数量）。

### 2.5.8 可运行示例

```powershell
.\gltk.exe run learn\examples\ch02_03_strings.glk
```

## 2.6 运行时类型系统

GrokLang 是**动态类型**：变量本身不写类型注解，值在运行时携带类型信息。

### 2.6.1 `typeof(x)` 

返回**类型名字符串**（不是类型对象）。实测常见结果：

| 值 | `typeof` 结果 |
|----|----------------|
| `null` | `"null"` |
| `true` / `false` | `"bool"` |
| 整数 | `"int"` |
| 浮点 | `"float"` |
| 字符串 | `"str"` |
| 数组 | `"array"` |
| 映射 | `"map"` |
| 函数 | 与实现相关（常为函数类描述） |

```glk
out.println(typeof(1))      // int
out.println(typeof(1.0))    // float
out.println(typeof("a"))    // str
out.println(typeof([1]))    // array
out.println(typeof({a:1}))  // map
out.println(typeof(null))   // null
```

### 2.6.2 类型之间如何协作（直觉）

- **算术**：优先在数字世界；混用 int/float 时常抬升到 float。  
- **比较**：同类型最直观；跨类型比较需谨慎，生产代码尽量先统一类型。  
- **拼接**：见 `+` 与字符串节。  
- **索引**：数组要整数下标；映射键在点语法下是字段名字符串。

### 2.6.3 尚无「静态类型检查」

错误多在**运行时**发现，例如对 null 取字段、对 map 当函数调用。  
开发时多用 `typeof`、小步 `out.println` 调试——逆向脚本场景下这很自然。

## 2.7 布尔、null 与真值

### 2.7.1 字面量

```glk
let ok = true
let no = false
let empty = null
```

`null` 表示「没有值」：未找到、可选结果为空、占位等。

### 2.7.2 真值表（Truthiness）

在 `if`、`while`、`&&`、`||`、`?:` 中，值会被解释为真或假：

| 假（falsy） | 真（truthy） |
|-------------|--------------|
| `null` | 非 0 数字 |
| `false` | 非空字符串 |
| `0` / `0.0` | 非空数组、非空 map |
| `""` | `true` |
| `[]` 空数组 | 大多数其它对象/函数 |
| `{}` 空映射 | |

```glk
out.println("" ? "T" : "F")   // F
out.println(0 ? "T" : "F")    // F
out.println([0] ? "T" : "F")  // T —— 数组非空即为真，哪怕元素是 0
```

### 2.7.3 逻辑运算

| 运算 | 含义 |
|------|------|
| `&&` | 逻辑与（短路：左边假则不算右边） |
| `\|\|` | 逻辑或（短路：左边真则不算右边） |
| `!` | 逻辑非 |

```glk
true || expensive()   // 不会调用 expensive（若已短路）
false && expensive()
!false                // true
!0                    // true（0 为假）
```

### 2.7.4 比较运算

```glk
==  !=  <  <=  >  >=
```

```glk
1 == 1
"a" == "a"
2 > 1
```

相等对字符串是内容比较（实现按值语义处理字符串内容）。

### 2.7.5 可运行示例

```powershell
.\gltk.exe run learn\examples\ch02_04_types_truth.glk
```

## 2.8 变量：`let` 与赋值

### 2.8.1 绑定

```glk
let x = 10
let name = "demo"
let flag = true
```

`let` 引入名字并绑定到右侧表达式的值。

### 2.8.2 赋值

```glk
x = x + 1
name = "other"
```

赋值目标还可以是：

```glk
arr[i] = value
obj.field = value
obj["key"] = value
```

### 2.8.3 作用域（第 2 章级说明）

- 函数体内的 `let` 是**局部**于该函数（及块结构，细节在第 3 章展开）；  
- 文件顶层的 `let` 往往作为**全局**使用（如教程里的配置常量）；  
- 未定义名字就读取 → 运行时报错。

### 2.8.4 引用语义（数组 / 映射）

数组和映射在 VM 里以引用方式持有：

```glk
let a = [1, 2, 3]
let b = a
b[0] = 9
// 此时 a[0] 也是 9
```

数字、布尔、字符串赋值是「值的拷贝/不可变内容」直觉：改 `b` 不会回头改已拷贝的数字。

## 2.9 运算符与优先级

### 2.9.1 分类一览

| 类别 | 运算符 |
|------|--------|
| 一元 | `-` `!` `~` |
| 乘除模 | `*` `/` `%` |
| 加减 | `+` `-` |
| 移位 | `<<` `>>` |
| 关系 | `<` `<=` `>` `>=` |
| 相等 | `==` `!=` |
| 位与/异或/或 | `&` `^` `\|` |
| 逻辑与/或 | `&&` `\|\|` |
| 三元 | `?:` |
| 赋值 | `=`（语句级，不是表达式链式赋值风格） |

### 2.9.2 优先级直觉（从高到低，简化）

```text
高  一元  - ! ~
    * / %
    + -
    << >>
    关系  < > <= >=
    相等  == !=
    位运算  &  ^  |
    &&
    ||
    ?:
低  （赋值是语句）
```

**拿不准就加括号**——可读性永远优先。

```glk
1 + 2 * 3      // 7
(1 + 2) * 3    // 9
```

### 2.9.3 括号

`(` `)` 用于：

1. 函数调用：`f(x, y)`  
2. 分组：`(a + b) * c`  
3. 提高可读性：`(score >= 60) ? "pass" : "fail"`

## 2.10 三元运算符 `cond ? a : b`

```glk
let grade = score >= 60 ? "pass" : "fail"
```

语义：

1. 计算 `cond` 的真值；  
2. 真则取 `a`，假则取 `b`；  
3. **只会计算**被选中的那一支（短路）。

优先级低于 `||`，复杂条件请加括号：

```glk
let t = (a && b) ? x : y
```

## 2.11 数组与映射

### 2.11.1 数组字面量

```glk
let empty = []
let xs = [1, 2, 3]
let mix = [1, "two", true]  // 动态类型允许异质元素（慎用）
```

### 2.11.2 下标

```glk
xs[0]        // 第一个元素，从 0 开始
xs[len(xs)-1]
xs[1] = 100
```

下标越界会运行时错误——逆向脚本读二进制时，务必先检查 `len`。

### 2.11.3 映射（map）字面量

```glk
let m1 = {name: "demo", port: 8080}
let m2 = {"full-name": "x", "a": 1}
```

- 键可以是标识符 `name`（等同字段名 `"name"`）；  
- 也可以是字符串键 `"full-name"`（可含特殊字符）。

### 2.11.4 字段访问与下标访问

```glk
m1.name          // 点语法
m1["name"]       // 下标语法，等价于字段
m1.port = 9090
```

点语法要求字段名是合法标识符；键为 `"full-name"` 时只能用 `m["full-name"]`。

### 2.11.5 ★ 致命坑：map 字面量中的「名字」求值

实战中出现过：

```glk
// 文件顶层全局
let NODE_HOST = "example.com"
fn builtin_cfg() {
  return {"server": NODE_HOST}  // 可能变成 null！
}
```

`json.stringify` 会看到 `"server": null`，于是配置解析报 `proxy.server required`。

**经验规则（请当作纪律）：**

| 写法 | 可靠性 |
|------|--------|
| `{"server": "example.com"}` 纯字面量 | ✅ 最稳 |
| `let m = {}` 然后 `m.server = host` | ✅ 推荐（局部/全局变量都行） |
| 函数**局部** `let host = ...; {server: host}` | 多数情况可用，但不要当规范依赖 |
| **顶层全局名**直接塞进 `{ }` 字面量 | ⚠️ 高风险 null |

```glk
// A. 字面量直接写死
let good = {"server": "example.com"}

// B. 先空 map，再赋值（变量一定可用）
let host = "example.com"
let good2 = {}
good2.server = host
```

**配置、代理节点、路径表：只用 A 或 B。** 这是当前写 GrokLang 的刚需纪律。

### 2.11.6 `range`

内建函数，生成整数数组，常用于 for（第 3 章）：

```glk
range(5)         // 0..4
range(1, 4)      // 1,2,3
```

## 2.12 内建转换、打印与类型工具

### 2.12.1 常用内建（无需 import）

| 名称 | 作用 |
|------|------|
| `typeof(x)` | 类型名字符串 |
| `len(x)` | 长度 |
| `int(x)` | 转为整数（如 `int("42")`） |
| `to_str(x)` | 转为字符串（推荐） |
| `str(x)` | 文档中的转换函数，但易被模块名覆盖 |
| `range(...)` | 整数序列数组 |
| `print` / `println` | 全局打印（也可用 `out` 模块） |

### 2.12.2 `out` 模块

```glk
import out

out.println("a", 1, true)  // 多参数打印
out.print("no newline")
```

第 1 章起我们统一用 `out.println`，与模块化风格一致。

### 2.12.3 命令行参数 `args`

```glk
fn main(args) {
  // gltk run file.glk -- a b c
  // args 通常包含 a b c
  out.println(len(args))
  if len(args) > 0 {
    out.println(args[0])
  }
  return 0
}
```

`gltk run` 里，`--` 后面的参数传给脚本（以你本机 CLI 行为为准；教程示例按此约定编写）。

## 2.13 表达式 vs 语句（第 2 章边界）

### 表达式

有值：字面量、运算、调用、三元、下标等。

```glk
1 + 2
f(x)
a[i]
cond ? 1 : 0
```

### 语句

完成动作：绑定、赋值、控制流、`return`、表达式语句等。

```glk
let x = 1
x = 2
out.println(x)
return 0
```

第 2 章你写的程序几乎都是：

```text
import ...
fn main(args) {
  let ...
  表达式 / 打印
  return 0
}
```

函数与控制流的系统化展开见第 3 章。

## 2.14 常见错误清单（必读）

| 症状 | 可能原因 | 处理 |
|------|----------|------|
| `7/2` 得到 `3` | int 整除 | 用 `7.0/2` 或接受整除 |
| `str(42)` → cannot call map | `str` 被模块全局覆盖 | 用 `""+42` 或 `to_str(42)` |
| map 字段突然 `null` | 全局名塞进 `{ "k": 全局变量 }` | 字面量写死或先 `{}` 再赋值 |
| `user-name` 解析怪异 | `-` 是减号 | 用 `user_name` 或字符串键 |
| 中文标识符 | 标识符规则是 ASCII | 中文只放在字符串里 |
| 字符串路径 `\` 消失 | 转义 | `\\` 或改用 `/` |
| 忘记 `import out` | 模块未导入 | 文件头加 `import out` |
| `main` 不存在 | 入口缺失 | 必须有 `fn main(...)` |
| 比较用了 `=` | `=` 是赋值 | 相等用 `==` |

## 2.17 本章小结

1. **词法**决定源码如何切开：注释、标识符、关键字、数字、字符串、运算符。  
2. **类型**在运行时由值携带；`typeof` / `len` / 真值规则是调试三件套。  
3. **字符串**是日常主力：转义、插值、多行、`+` 拼接；慎用 `str()`。  
4. **数字**注意 **int 整除** 与十六进制。  
5. **map 字面量不要塞变量**——用字面量或先建后赋。  
6. **表达式**靠运算符与优先级组成；拿不准就括号。

你现在已经可以描述数据、做计算、拼日志——还差「把表达式串成算法结构」。
